FAQ

What is this?

Kickoff is a scoping tool for analysts and ops professionals. When an executive asks a vague question ("why is retention down?"), the tool decomposes it into a structured analysis brief through a five-minute AI-powered interview. Every brief gets a shareable permalink you send to the exec for scope alignment before you write any SQL.

Is it really free?

Yes. Runs on Cloudflare Workers AI free tier (Llama 3.2 3B) and Cloudflare KV free tier for storage. No signup, no API key, no credit card. Just paste a question and go.

Do you store my data?

Every completed brief is stored in Cloudflare KV so the permalink continues to work. No email, no name, no IP is collected. Treat every permalink as public — anyone with the URL can view the brief.

Which AI model?

Currently Llama 3.2 3B via Cloudflare Workers AI. Small model, but strong enough for decomposition tasks. If you hit quality issues, tell me via LinkedIn — we can upgrade to a bigger model on a paid tier post-launch.
