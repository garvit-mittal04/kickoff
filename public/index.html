FAQ

What is this?

Kickoff is a scoping tool for analysts and ops professionals. When an executive asks a vague question ("why is retention down?"), the tool decomposes it into a structured analysis brief through a five-minute AI-powered interview. Every brief becomes a shareable permalink you send to the exec for scope alignment before you write any SQL.

Is it really free?

Yes. Runs entirely on Cloudflare's free tier — Workers for the backend, Workers AI (Llama 3.2 3B) for the model, KV for storage, Pages for the frontend. No signup, no API key, no credit card. If usage grows past free-tier limits, that's an upgrade problem, not a today problem.

Do you store my data?

Every completed brief is stored in Cloudflare KV so the permalink keeps working. No email, no name, no IP is collected. Treat every permalink as public — anyone with the URL can view the brief.

Which AI model?

Currently Llama 3.2 3B via Cloudflare Workers AI. Small model, strong enough for decomposition tasks. If you hit quality issues, drop feedback on the GitHub repo — a paid tier upgrade to a bigger model is a one-line change.

Can I use it for team briefs?

v1.0 is single-user only. Team workspaces, brief editing, and comments land in v2. Every permalink is already shareable — that covers most collaboration for now.
