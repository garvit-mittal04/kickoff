FAQ

What is this?

Kickoff is a scoping tool for analysts and ops professionals. When an executive asks a vague question ("why is retention down?"), the tool decomposes it into a structured analysis brief through a five-minute AI-powered interview. The brief becomes a shareable permalink you send to the exec for scope alignment before you write any SQL.

Is it really free?

Yes. Runs on Cloudflare Workers AI free tier (Llama 3.2 3B). No signup, no API key, no credit card, no rate limit for individual users. If usage grows and needs a paid tier, that's an upgrade problem — not a today problem.

Do you store my data?

v1.0 does not persist briefs yet — that ships Day 56. Right now the brief renders in your browser and you can copy the text before closing the tab. Once permalinks ship tomorrow, every brief gets a stable URL.

Which AI model?

Currently Llama 3.2 3B via Cloudflare Workers AI. Small model, but strong enough for decomposition tasks. If you hit quality issues, tell me via LinkedIn — we can swap to a bigger model on the paid tier post-launch.
